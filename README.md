# Strava Fitness & Wellness Analytics

## Project Overview

This project analyses fitness-tracking data to understand user activity, sleep patterns, calories burned, and weight/BMI behaviour.

The goal is to identify meaningful patterns in user fitness behaviour and engagement that can support data-driven wellness and fitness initiatives.

## Business Problem

A fitness tracking platform collects user activity, sleep, and weight/BMI data but needs to understand how users behave, track their fitness activities, and engage with fitness tracking technology.

## Analysis Objectives

* Analyse daily user activity levels
* Understand fitness tracking consistency
* Explore sleep patterns and their relationship with activity
* Analyse the relationship between daily steps and calories burned
* Examine weight and BMI patterns

## Key Questions

* How active are users based on their daily activity?
* How consistently do users track their fitness activities?
* What patterns can be observed between activity and sleep?
* How are daily steps related to calories burned?
* What patterns can be observed in weight and BMI data?

## Tools & Technologies

* **Python** — Data cleaning, exploratory data analysis and visualization
* **Pandas & NumPy** — Data manipulation and analysis
* **Matplotlib & Seaborn** — Data visualization
* **SQL Server** — Data querying, analysis and joining datasets
* **Streamlit** — Interactive dashboard

## Project Workflow

1. Data loading and cleaning
2. Exploratory Data Analysis using Python
3. Data analysis and joins using SQL
4. Interactive dashboard development using Streamlit
5. Insights and business recommendations
